# Prompt Log
**Инструмент:** deepseek v4-flash
## Задание 1: Создание полноценного веб-приложения.
### Промпт 1
**Промпт:** "Напиши docker-compose.yml, который поднимает три сервиса: Python (FastAPI), Go (Gin) и Rust (простой HTTP-сервер, например, на actix-web). Используй общую сеть. Для Go и Rust примени многоэтапную сборку, для Python – минимальный образ python:3.12-slim."
**Результат:** Создан docker-compose.yml и все необходимые файлы для трёх сервисов.
### Промпт 2
**Промпт:** "Добавь в docker-compose.yml depends_on, чтобы Python-сервис ждал запуска Go и Rust. Исправь относительные пути к Dockerfile, если они лежат в подпапках. Добавь имена контейнеров"
**Результат:** Добавлен depends_on для Python-сервиса — он будет ждать запуска Go и Rust.
### Промпт 3
**Промпт:** "Проверь, что все сервисы видят друг друга по имени контейнера в общей сети. Убери лишние маппинги портов для внутреннего взаимодействия"
**Результат:** Итоговая логика:
     - Python (FastAPI) — порт 8000 (доступен снаружи через network_mode: host), зависит от go-gin и
        rust-actix.
     - Go (Gin) — порт 8080 (доступен снаружи через network_mode: host), доступен внутри сети как
       http://go-gin:8080.
     - Rust (actix-web) — порт 8082 (доступен снаружи через network_mode: host), доступен внутри сети как
       http://rust-actix:8082.
    Все три сервиса используют network_mode: host и общий volume shared_data, смонтированный в /data.
### Итого
- Количество промптов: 3
- Что пришлось исправлять вручную: запуск докер образа и проверка работоспособности упакованных в него сервисов.
- Время: ~30 мин
## Задание M7: Использовать volume для обмена данными между контейнерами.
### Промпт 1
**Промпт:** "Добавь в docker-compose.yml общий volume с именем shared_data. Смонтируй его во все три контейнера в папку /data. Напиши код для каждого сервиса, который умеет писать в /data/log.txt текущее время и читать содержимое файла по отдельным эндпоинтам."
**Результат:** docker-compose.yml — добавлен общий volume shared_data, смонтированный в
/data для всех трёх сервисов.
### Промпт 2
**Промпт:** "При одновременной записи из разных контейнеров файл иногда повреждается. Реализуй синхронизацию с помощью файловых блокировок или добавь мьютекс в каждый сервис, чтобы они не писали строго одновременно. Также исправь права доступа: сейчас файл создаётся от root, и другие контейнеры не могут его перезаписать."
**Результат:** Права доступа
    Добавлен сервис init-shared-data на базе Alpine, который создаёт
    /data/log.txt с правами 666 до запуска основных контейнеров. Все сервисы
    зависят от него через depends_on: condition: 
    service_completed_successfully.
### Промпт 3
**Промпт:** "Добавь проверку: после записи из одного сервиса другой должен сразу видеть изменения. Напиши тестовый скрипт, который последовательно вызывает /write у всех трёх сервисов и затем /read для проверки консистентности."
**Результат:**Скрипт test_consistency.sh готов. Вот что он проверяет:
     1. Последовательный `/write` — вызывает запись времени у каждого сервиса (go
         → python → rust)
     2. `/read` у всех трёх — забирает содержимое файла от каждого сервиса
     3. Сравнение — все три ответа должны быть байт-в-байт идентичны
     4. Подсчёт записей — файл должен содержать ≥ 3 строк
     5. Циклический тест — 3 раунда: запись от всех сервисов + проверка
        консистентности
### Итого
- Количество промптов: 3
- Что пришлось исправлять вручную: запуск докер образа, проверка правильной и взаимосвязанной работы сервисов.
- Время: ~25 мин

**Результат:** - Все три контейнера строго соблюдают CPU лимиты — ни один не превысил свою квоту даже при максимальной нагрузке

## Задание B7: Создать multi-stage сборку для Python-приложения с Rust-расширением.
### Промпт 1
**Промпт:** "Напиши multi-stage Dockerfile для Python-приложения, которое использует Rust-расширение (pyo3 + maturin). Первый этап: компиляция Rust-крейта. Второй этап: сборка Python-колеса с помощью maturin. Третий этап: финальный образ на python:3.12-slim, куда копируется только колесо и устанавливается."
**Результат:** Итоговый multi-stage Dockerfile

      ┌─────────────────────────────────────────────────────────┐
      │  Этап 1: rust-builder (rust:1.88-slim)                  │
      │  ┌───────────────────────────────────────────────────┐  │
      │  │ COPY Cargo.toml + src/                            │  │
      │  │ RUN cargo build --release                         │  │
      │  │ → Компилирует Rust-крейт (cdylib для Python)      │  │
      │  └───────────────────────────────────────────────────┘  │
      │                          ↓ COPY target/                 │
      │  Этап 2: wheel-builder (python:3.12-slim + gcc)         │
      │  ┌───────────────────────────────────────────────────┐  │
      │  │ pip install maturin                               │  │
      │  │ COPY Cargo.toml + src/ + pyproject.toml           │  │
      │  │ COPY --from=rust-builder target/  ← кэш крейтов   │  │
      │  │ RUN maturin build --release --out dist            │  │
      │  │ → Собирает .whl колесо с Rust-расширением         │  │
      │  └───────────────────────────────────────────────────┘  │
      │                          ↓ COPY dist/*.whl              │
      │  Этап 3: runtime (python:3.12-slim)                     │
      │  ┌───────────────────────────────────────────────────┐  │
      │  │ pip install --no-cache-dir dist/*.whl             │  │
      │  │ COPY main.py                                      │  │
      │  │ → Только wheel + код, нет gcc/rust/cargo          │  │
      │  └───────────────────────────────────────────────────┘  │
      └─────────────────────────────────────────────────────────┘
### Промпт 2
**Промпт:** "Поправь пути: Rust-код лежит в папке rust_extension, Python-код – в python_app. Maturin должен видеть Cargo.toml из папки расширения. Исправь ошибку: "maturin build --manylinux off" не может найти pyproject.toml."
**Результат:** Кэширование по этапам
    ┌────────┬───────────────────────┬──────────────────────────────┐
    │ Этап   │ Что кэшируется        │ Когда инвалидируется         │
    ├────────┼───────────────────────┼──────────────────────────────┤
    │ `ru... │ target/ с объектам... │ При изменении Cargo.toml ... │
    │ `wh... │ maturin + скачанны... │ При изменении Cargo.toml,... │
    │ `ru... │ Только .whl файл      │ При изменении main.py        │
    └────────┴───────────────────────┴──────────────────────────────┘
### Промпт 3
**Промпт:** "Уменьши размер финального образа: убери из него все build-зависимости (rustc, cargo, gcc), оставь только python:3.12-slim и установленный wheel. Также добавь проверку, что Rust-функция корректно вызывается из Python (например, эндпоинт /rust_hello)."
**Результат:** Финальный образ (runtime) содержит только:
- python:3.12-slim — базовый Python
